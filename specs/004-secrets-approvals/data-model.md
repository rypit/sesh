# Data model: Secrets and approvals

## Approval request (`gateway.approvals`)

| Field | Notes |
|---|---|
| `id` | 16 random bytes, hex; shown to the agent |
| `agent`, `connector`, `method` | from the capability and the call, never from the script's claims |
| `fingerprint` | hex SHA-256 of `agent \0 connector \0 method \0 canonical-json(args)`; canonical = keys sorted, no whitespace |
| `shown_text` | the gateway-written text (FR-003); argument values quoted, each cut to 200 characters, the whole text cut to 1,500 |
| `secret_sha256` | hex SHA-256 of the 32-byte approval secret; the secret itself is never stored |
| `created_at`, `expires_at` | default lifetime 15 minutes (`approval_ttl_secs`) |
| `state` | `pending` → `approved` \| `denied` \| `expired`; `approved` → `used` \| `expired`; no other moves |
| `reason` | for denials: `denied by the person`, `approval channel unavailable` |
| `decided_at`, `used_at` | |

Grants: `sesh_gateway` gets INSERT, SELECT and UPDATE, but not DELETE.

## Credential form (`gateway.credential_forms`)

| Field | Notes |
|---|---|
| `id` | 16 random bytes, hex |
| `connector`, `name` | must be a credential the connector declares |
| `secret_sha256` | of the form's 32-byte secret |
| `created_at`, `expires_at` | default 30 minutes (`form_ttl_secs`) |
| `used_at` | set once; a second submit is refused |

## Credential (in Infisical, project `sesh`, environment `prod`)

The key is `<CONNECTOR>__<NAME>`, for example `TESTCRED__TOKEN`, at path
`/`. The value lives only in Infisical. The gateway keeps no copy beyond a
call's lifetime.

## Connector credential declaration (`ConnectorDescriptor.credentials`)

A list of names (`[A-Z][A-Z0-9_]{0,63}`). A method of that connector is
refused with "not set up yet" while any declared credential is missing.

## Audit entry additions (`gateway.audit`)

There are no new columns. `connector` and `method` are the call's, and
`reason` carries the event:

| Event | `outcome` | `reason` |
|---|---|---|
| Approval requested | `refused` | `approval pending <id>` |
| Rate limit hit | `refused` | `too many approval requests` |
| Approval decided | `allowed` or `refused` | `approval <id> approved` or `approval <id> denied` |
| Approval expired | `refused` | `approval <id> expired` |
| Approval refused | `refused` | `approval refused: <used\|expired\|unknown\|wrong agent>` |
| Gated call ran | `allowed` | `approved <id>` |
| Credential form | `allowed` | `credential.request <connector>/<NAME>`, `credential.fill <connector>/<NAME>` |
| Credential used | the call's outcome | `credential <connector>/<NAME>` |
