# Contract: sesh configuration files

All live in `$SESH_DATA_DIR` (default `~/.local/share/sesh`), never in the
repository.

## `sesh.toml`

```toml
[inference]
base_url = "http://192.168.1.20:11434/v1"   # any OpenAI-compatible server
# api_key_env = "INFERENCE_API_KEY"         # optional; value read from the environment
timeout_secs = 120

[aliases]
agent-main = "qwen3-30b-a3b"                 # the server's model name

[ports]
webui = 3000
router = 4000
```

## `secrets.env`

`KEY=value` lines, mode 0600, generated by `sesh init` / `sesh up`.
Never committed, printed or logged. Read by Compose through `env_file`.

## `litellm.yaml` (rendered, do not edit)

```yaml
model_list:
  - model_name: agent-main
    litellm_params:
      model: openai/qwen3-30b-a3b
      api_base: http://192.168.1.20:11434/v1
      api_key: os.environ/INFERENCE_API_KEY   # or "none"
      timeout: 120
general_settings:
  master_key: os.environ/LITELLM_MASTER_KEY
  database_url: os.environ/DATABASE_URL
litellm_settings:
  telemetry: false
```
